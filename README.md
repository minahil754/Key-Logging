# Key-Logging
Python-based keylogging demonstration in a controlled test environment, completed for the Arch Technologies Cyber Security Internship.

## Overview
This project was completed as Task 2 of my Arch Technologies Cyber Security Internship. It demonstrates keyboard-event logging in a controlled test window using Python.

## Tools and Technologies
- Python
- Tkinter
- Visual Studio Code
- Windows

## Project Files
- `key_logger_demo.py` — Python demonstration script.
- `keystroke_demo.txt` — local test log output.
- Screenshots — evidence of the code, running program, and log output.
- Task report — procedure, results, security risks, and prevention measures.
